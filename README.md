# ⚡ J.A.R.V.I.S. ULTRA (Mark L)

**True Real-Time Voice & AI Assistant for Windows.**
Powered by **Google Gemini 2.0 Flash** + **Windows Native Audio Synthesizer**.

## 🚀 How to Run
Double-click `run_jarvis.bat` or run:
```bash
python jarvis_app.py
```

## ✨ Capabilities
- 🔊 **Speaks out loud** every response using Windows SAPI voice.
- 🎤 **Listens with microphone** via Google Speech Recognition.
- 🧠 **Google Gemini 2.0 Flash** intelligence (answers anything in Somali and English).
- 💻 **Controls Windows PC**: Opens YouTube, searches Google, launches apps, adjusts volume, captures screenshots, and monitors CPU/RAM.
